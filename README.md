# Estudaí!

**Plataforma colaborativa de estudos**

O Estudaí! é uma plataforma desenvolvida para facilitar o compartilhamento de materiais acadêmicos e a colaboração entre estudantes. Reúne apostilas, resumos e comunidades de estudo em um único ambiente.

## Funcionalidades

- **Repositório de materiais:** compartilhamento e acesso a apostilas e resumos.
- **Comunidades de estudo:** criação e participação em grupos de aprendizagem.
- **Chat colaborativo:** comunicação entre os participantes das comunidades.
- **Lista de participantes:** visualização dos integrantes de cada comunidade.
- **Contas de usuário:** cadastro, login e gerenciamento de acesso.
- **Dashboard administrativo:** painel restrito para acompanhamento e administração da plataforma.
- **Sistema de feedback:** espaço para avaliações, sugestões e opiniões dos usuários.

## Tecnologias utilizadas

O projeto utiliza tecnologias modernas para oferecer uma aplicação organizada, segura e escalável.

| Camada | Tecnologia |
|---|---|
| Front-end | HTML, CSS e JavaScript |
| Back-end | Node.js e Express |
| Banco de dados | PostgreSQL |
| Integração de banco | Supabase |
| Segurança | Helmet e validação de dados |
| Testes | Test runner nativo do Node.js |
| Hospedagem | Compatível com plataformas de deploy modernas |

## Organização do projeto

O Estudaí! possui uma arquitetura dividida em duas partes principais:

- **Front-end:** responsável pela interface, navegação e interação com os usuários.
- **Back-end:** responsável pelas regras de negócio, processamento de informações e comunicação com o banco de dados.

O projeto também conta com módulos específicos para autenticação, administração, materiais, comunidades, feedback e monitoramento da aplicação.

## Segurança e confiabilidade

A plataforma conta com mecanismos de proteção e validação para proporcionar uma experiência mais segura.

Entre os recursos implementados estão:

- Proteção de acesso às funcionalidades restritas.
- Validação de informações enviadas pelos usuários.
- Controle de permissões.
- Proteção de requisições.
- Gerenciamento seguro de sessões.
- Restrição de formatos e tamanhos de arquivos.
- Tratamento de erros.
- Testes automatizados para verificar o funcionamento da aplicação.

## Experiência do usuário

A interface foi desenvolvida para oferecer navegação intuitiva, organização visual e facilidade de utilização.

O sistema possui páginas adaptadas para diferentes dispositivos, incluindo computadores e celulares.

## Infraestrutura e publicação

O projeto utiliza PostgreSQL como banco de dados e possui compatibilidade com serviços modernos de hospedagem.

Sua arquitetura permite implantação em ambientes de produção e integração com serviços externos de armazenamento e comunicação.

A infraestrutura pode ser ampliada conforme o crescimento da plataforma e o aumento da quantidade de usuários.

## Desenvolvimento e evolução

O Estudaí! está estruturado para receber novas funcionalidades e melhorias continuamente.

Entre as possibilidades de evolução estão:

- Integração com armazenamento externo de arquivos.
- Implementação de comunicação em tempo real.
- Recuperação de senha e confirmação de e-mail.
- Paginação e otimização de consultas.
- Ampliação dos recursos administrativos.
- Novas ferramentas de aprendizagem colaborativa.
- Integração de recursos de inteligência artificial.

## Objetivo

O objetivo do Estudaí! é tornar o processo de aprendizagem mais acessível, colaborativo e organizado, conectando estudantes e facilitando o compartilhamento de conhecimento.
